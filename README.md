# Al-Gups

React + Vite application for the GUPS Alumni Association.

## Prerequisites

- Node.js 20 or newer
- npm

## Install dependencies

From the project directory, run:

```bash
npm install
```

## Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

To expose the server on all network interfaces:

```bash
npm run dev -- --host 0.0.0.0
```

## Create a production build

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```

## Format the code

```bash
npm run format
```
